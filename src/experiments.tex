\subsection{Evaluation Questions and Setup}
State which claim each experiment tests. Describe the data or study
materials, inclusion criteria, baselines, evaluation metrics, and procedure.
Explain how comparisons are made fair and how uncertainty is assessed.
Report actual experimental conditions instead of inventing missing details.

Describe the origin and relevant properties of the evaluation material.
Explain how development and evaluation subsets are separated, including
any grouping needed to prevent closely related examples from appearing in
both. State the scope of the evaluation: what variation is represented and
which operating conditions are absent. If the study uses simulations or
constructed examples, explain how those conditions relate to the intended
application and where the comparison may break down.
Cite the dataset or study-material source here~\cite{dataset}. Record the
release, subset, and split used so that the reference identifies the resource
and the text identifies your specific use of it.

Define each evaluation metric before interpreting its values. Give its
units, preferred direction, aggregation rule, and treatment of failed or
missing outputs. Explain why the chosen metrics reflect the research
question. If different metrics emphasize different aspects of performance,
state how those differences will inform the interpretation rather than
selecting only the metric that favors the proposed approach.
Use the metric reference to credit an adopted definition~\cite{metric}.
Describe any deviation from that definition and its effect on comparability.

\subsection{Baselines and Comparison Protocol}
Select baselines that test the contribution you actually claim. Include a
simple reference method where useful, and explain the relevance of more
complex alternatives. Document whether baseline implementations are reused
or reimplemented. Specify the settings used for each method and describe
how the development budget is made comparable across approaches.
Cite the baseline's original method~\cite{baseline} and any implementation
dependency separately~\cite{software}. A comparison should make clear both
what was evaluated and how it was implemented.

State how many independent runs or evaluation units are used and why.
Describe how variation is summarized and identify the unit over which an
uncertainty interval is computed. Reference a suitable reproducibility
protocol when one informs the design~\cite{reproducibility}, while reporting
your actual settings rather than relying on the citation for those details.

time. Keep the input data, evaluation protocol, and unrelated settings
fixed. Explain what replaces a disabled component so that each variant
remains a valid method rather than a broken implementation.
Use an experimental-design reference to motivate the controlled comparison
where relevant~\cite{ablation}. Explain how the design separates the effect
of the component from changes in the evaluation procedure.

Interpret each comparison in terms of the component's intended role.
Consider whether a change could arise from a different computational budget
or training procedure rather than the component itself. If the two
components interact, discuss what can be learned by removing both.
Do not describe a component as necessary or beneficial until the measured
results support that conclusion.

\subsection{Failure Cases and Summary of Evidence}
Describe unsuccessful cases alongside successful ones. Connect each failure
to a specific assumption or intermediate behavior, and distinguish an
observed pattern from a speculative explanation. State what additional
measurement would help identify the cause. Avoid using a few selected
examples to claim a general failure rate.

Close the evaluation by returning to its original questions. State which
claims are supported, which remain uncertain, and which were not tested.
Explain how the quantitative comparisons, qualitative examples, ablations,
and sensitivity analysis complement one another. This synthesis should
reflect your collected evidence rather than repeat a list of figure and
table captions.
